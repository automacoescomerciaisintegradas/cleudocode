# Andrej Karpathy's AI Development Principles

Guide for high-quality, efficient AI-assisted development.

## 1. Think Before Coding
- **Explicit Reasoning**: Always state the plan and rationale before writing code.
- **Challenge Ideas**: Identify potential pitfalls or better alternatives.
- **Clarification**: If any requirement is ambiguous, ask before implementing.

## 2. Simplicity First
- **Avoid Overengineering**: Write only what is necessary to solve the current problem.
- **Minimal Abstraction**: Don't create complex systems for simple tasks.
- **No Speculation**: Do not add features "just in case they are needed later".

## 3. Surgical Changes
- **Conformity**: Match the existing style, naming conventions, and patterns of the codebase.
- **Precision**: Modify only what is required.
- **Cleanups**: Only refactor code directly related to the change.

## 4. Goal-Driven Execution
- **Declarative Goals**: Define what the end state should look like.
- **Verification Loops**: Implement and then verify if the goal was met (tests/checks).
- **Iteration**: Loop until the specific success criteria are achieved.

When this skill is active, the agent must prioritize these principles in every step.
