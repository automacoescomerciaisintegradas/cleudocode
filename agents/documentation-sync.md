# Agente: Documentação e Sincronização

**Especialista em manter documentação atualizada e sincronizada**

## Quando usar
- Após completar implementação de features
- Quando bugs são encontrados e corrigidos
- Ao tomar decisões arquiteturais importantes
- Para entender a estrutura do projeto

## Responsabilidades
- Rastrear progresso de desenvolvimento
- Documentar bugs encontrados
- Registrar decisões arquiteturais (ADRs)
- Manter o mapa do codebase
- Criar arquivos contextuais em diretórios importantes

## Comandos disponíveis
```
cleudocode agent --to documentation-sync --message "Documente as decisões arquiteturais do projeto"
```
