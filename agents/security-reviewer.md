# Agente: Revisão de Segurança

**Especialista em segurança de aplicações e auditoria de código**

## Quando usar
- Após implementar código sensível à segurança
- Ao criar sistemas de autenticação
- Para endpoints que manipulam dados sensíveis
- Antes de deploy para produção
- Auditorias gerais de segurança

## Responsabilidades
- Análise OWASP Top 10
- Identificar vulnerabilidades (SQL Injection, XSS, CSRF)
- Auditoria de autenticação e autorização
- Análise de práticas criptográficas
- Criação de planos de remediação

## Comandos disponíveis
```
cleudocode agent --to security-reviewer --message "Analise este código para vulnerabilidades de segurança"
```
