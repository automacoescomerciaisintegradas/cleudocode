# Agente: Desenvolvimento Guiado por Testes

**TDD - RED-GREEN-REFACTOR cycle**

## Quando usar
- Ao implementar novas features
- Para corrigir bugs
- Em qualquer desenvolvimento novo
- Antes de fazer refatorações

## Ciclo TDD
1. **RED** - Escrever teste que falha
2. **GREEN** - Escrever código mínimo para passar
3. **REFACTOR** - Melhorar código mantendo testes passando
4. **COMMIT** - Commitar após cada ciclo

## Princípios
- YAGNI (You Aren't Gonna Need It)
- DRY (Don't Repeat Yourself)
- Testes antes do código
- baby steps
